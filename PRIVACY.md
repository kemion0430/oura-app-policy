# Privacy Policy — run log oura

Last updated: 2026-09-05

## Overview

This application ("the App") is a personal, single-user tool built and operated by an
individual for their own use. It is not a commercial product and has no users other
than its developer.

## What data the App accesses

With the user's explicit authorization through Oura's OAuth2 flow, the App reads the
following from the Oura API, for the authorizing user only:

- Daily sleep summaries and sleep periods
- Daily readiness
- Daily activity
- Daily stress

The App requests the `daily` scope only. It does not request or access heart rate
detail, workouts, tags, sessions, SpO2, or personal profile information.

## How the data is used

The data is stored in a private database controlled solely by the developer, and is
used only for the developer's own analysis of their sleep and training.

## What the App does NOT do

- It does not collect data from anyone other than the developer.
- It does not share, sell, or transfer data to any third party.
- It does not use the data for advertising, profiling, or training machine learning
  models offered to others.
- It does not display or publish the data publicly.

## Retention and deletion

Data is retained in the developer's private database for as long as it is useful for
personal analysis. The developer can delete it at any time. Revoking the App's
authorization in Oura's settings immediately stops all further access.
